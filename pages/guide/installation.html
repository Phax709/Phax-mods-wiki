📦 Installation de mods

Prérequis

  • Minecraft Java Edition
  • Un mod loader : Forge, NeoForge ou Fabric

Avec Forge ou NeoForge

  1. Téléchargez Forge ou NeoForge
  2. Lancez l'installateur et sélectionnez Install Client
  3. Ouvrez le launcher Minecraft et sélectionnez le profil Forge ou NeoForge
  4. Placez vos fichiers .jar dans le dossier mods/
Dossier mods :
Windows : %appdata%\.minecraft\mods\
macOS : ~/Library/Application Support/minecraft/mods/
Linux : ~/.minecraft/mods/

Avec Fabric

  1. Téléchargez Fabric Installer
  2. Lancez l'installateur
  3. Installez aussi Fabric API
  4. Placez vos mods dans le dossier mods/
Dossier mods :
Windows : %appdata%\.minecraft\mods\
macOS : ~/Library/Application Support/minecraft/mods/
Linux : ~/.minecraft/mods/
ℹ️ Note : Les mods de Phax709 ne sont actuellement pas disponibles sur Fabric. Cependant, ce guide reste valable pour l'installation de tout mod Fabric.
⚠️ Compatibilité : Les mods Forge, NeoForge et Fabric ne sont pas compatibles entre eux. Vérifiez toujours le mod loader requis.

Via une application (CurseForge, Modrinth, etc.)

Si vous utilisez une application comme CurseForge App, Modrinth App, Prism Launcher ou autre :

  1. Ouvrez l'application et accédez à la section Mods
  2. Utilisez la barre de recherche pour trouver le mod souhaité
  3. Vérifiez que la version Minecraft et le mod loader correspondent à votre profil
  4. Cliquez sur Installer
⚠️ Mod introuvable ? Si aucun résultat ne correspond à votre recherche, il est possible que le mod ne soit pas encore disponible pour votre version de Minecraft ou votre mod loader. Essayez de changer la version dans les filtres de recherche, ou consultez directement la page du mod sur CurseForge / Modrinth pour vérifier les versions supportées.
